# Design Reference (Non-Canonical)

> **NON-CANONICAL, Docs/DESIGN.md wins.**

Berkas dan folder di direktori ini merupakan artefak eksplorasi visual awal dan ekspor mockup desain grafis. Sesuai dengan arsitektur dan aturan desain produk SyncPod:

1. Dokumen kanonikal desain dan panduan sistem token adalah `Docs/DESIGN.md` dan `Docs/DECISIONS.md`.
2. Semua gaya antarmuka, warna, rasio kontras, dan batasan responsif mengacu pada token `apps/web/src/styles/tokens.css`.
3. Folder ini disimpan semata-mata sebagai referensi visual arsip semifinal hackathon.
