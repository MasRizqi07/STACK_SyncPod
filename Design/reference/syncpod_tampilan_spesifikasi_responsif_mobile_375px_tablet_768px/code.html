# Tujuan Sesi Sprint 1: Optimasi Algoritma Dijkstra

Konteks: Penentuan jalur terpendek dari satu titik sumber (Single-Source Shortest Path).
- Analisis struktur data Min-Heap Priority Queue O((V + E) log V).
- Invarian relaksasi: jika dist[u] + w(u, v) < dist[v], perbarui dist[v].

// Inisialisasi struktur heap priority queue pada C++20

- Tantangan aktif: Bagaimana merepresentasikan edge berbobot negatif?
Catatan: Dijkstra mengasumsikan non-negative weights. Jika terdapat negative edge, gunakan Bellman-Ford untuk deteksi negative cycle.
